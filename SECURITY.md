# Sicherheit

## Unterstützte Versionen

Sicherheitskorrekturen gibt es für die jeweils neueste Version von Signal.

## Eine Lücke melden

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue. Nutze stattdessen die private Meldefunktion von
GitHub: im Projekt unter **Security → Report a vulnerability**
(https://github.com/Leon510/signal/security/advisories/new).

Hilfreich sind:

- betroffene Version und Windows-Version,
- eine Beschreibung, wie sich die Lücke auslösen lässt (z. B. eine präparierte Playlist oder EPG-Datei),
- die möglichen Folgen.

Du bekommst in der Regel innerhalb einer Woche eine Rückmeldung.

## Was besonders interessiert

Signal verarbeitet Daten aus fremden Quellen: Playlisten, Programmführer, Logos und Streams. Besonders relevant
sind deshalb Wege, über die solche Daten

- Code im Programm ausführen (z. B. über Sendernamen, Beschreibungen oder Links),
- auf Dateien des Computers zugreifen,
- die App zum Absturz bringen oder dauerhaft blockieren.

Bitte füge Meldungen **keine echten Playlist-Links mit Zugangsdaten** bei.
